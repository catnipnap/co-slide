# Co-Slide (코-슬라이드)

> **실시간 AI 에이전트 협업 & 네이티브 PPTX 변환을 지원하는 차세대 프레젠테이션 에디터**

Co-Slide는 VS Code 및 Google Antigravity IDE 내부에서 동작하는 네이티브 커스텀 슬라이드 에디터입니다.
웹 뷰 기반의 섬세한 위지윅(WYSIWYG) 편집과 실시간 AI 에이전트 양방향 협업, 1:1 파워포인트(.pptx) 내보내기 및 자동 버전 기록(히스토리) 시스템을 제공합니다.

---

## 주요 기능

1. **완벽한 WYSIWYG 슬라이드 편집**:
   - 16:9 (1920×1080) 풀HD 도화지 기반 캔버스 엔진
   - 텍스트 상자, 도형(사각형, 원형, 삼각형, 화살표, 별, 말풍선 등), 미디어(이미지, 비디오 카드) 지원
   - 정밀 테이블(표) 엔진: 셀별 서식(글자색/배경색/테두리), 크기 조절, 행/열 삽입 및 삭제

2. **통합 상단 서식 툴바**:
   - 폰트 실시간 검색 및 PC 로컬 시스템 폰트 원클릭 스캔
   - 파워포인트 표준 포인트(pt) 단위 일원화
   - 정렬, 투명도, 테두리 굵기 및 색상 팔레트

3. **안내선 & 스마트 스냅 (Snap)**:
   - 가로/세로 정중앙 안내선(눈금선) 원클릭 토글
   - 개체 이동 시 정중앙 자석 스냅(Snap) 지원으로 손쉬운 레이아웃 배치

4. **안전 백업 & 버전 기록 (히스토리)**:
   - 저장(`Ctrl+S` 또는 `💾 저장` 버튼) 시 원본 자동 백업 (`_backup_날짜_시간.slide.json`)
   - `📜 기록` 버튼을 통해 과거 버전 목록 확인 및 원클릭 복원 지원

5. **AI 에이전트 양방향 실시간 동기화**:
   - 사용자가 캔버스를 편집하면 `*.slide.json` 파일에 즉시 동기화
   - AI 에이전트가 채팅창 명령을 받아 JSON을 수정하면 에디터 캔버스가 실시간 자동 갱신
   - 저장 시점 캔버스 캡처 생성으로 에이전트가 시각적 상태를 직접 확인

6. **네이티브 파워포인트 (.pptx) 1:1 완벽 출력**:
   - 단순 화면 캡처가 아닌 순수 파워포인트 셰이프/텍스트/테이블 객체로 100% 온전하게 변환

---

## 사용 방법

1. **새 슬라이드 파일 생성**:
   - 탐색기에서 새 파일 생성: `[파일명].slide.json` (확장자가 `.slide.json`이면 자동으로 전용 에디터로 열립니다.)
   - 또는 명령 팔레트(`Ctrl+Shift+P`) ➔ `Slide Studio: 새 프레젠테이션 생성`
2. **이어서 작업하기**:
   - 저장된 `*.slide.json` 파일을 더블클릭하면 에디터가 즉시 실행됩니다.
3. **저장 및 PPTX 출력**:
   - 상단 헤더의 `💾 저장` (단축키 `Ctrl+S`)으로 저장 및 백업
   - `🚀 PPTX 내보내기` 버튼으로 파워포인트 파일 생성
